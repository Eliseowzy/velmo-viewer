# Velmo Viewer へようこそ

Finder で `.md` ファイルを選んで**スペースキー**を押すと、このように整った記事として表示されます。

## 対応している内容

- **太字**、*斜体*、~~取り消し線~~、`インラインコード`、[リンク](https://velmo.ink)
- [x] タスクリスト
- [ ] 脚注[^1]、表、数式

> 書くことは、考えることの延長だ。

```swift
func greet(_ name: String) -> String {
    return "Hello, \(name)!" // シンタックスハイライト
}
```

| ショートカット | 動作 |
| -------------- | ---- |
| スペース       | クイックルック |
| ⌥ スペース     | フルスクリーンで表示 |

インライン数式 $e^{i\pi} + 1 = 0$ と、ブロック数式：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

ECharts のグラフ。コードブロックに JSON 形式の option を書きます：

```echarts
{
  "tooltip": {},
  "xAxis": { "type": "category", "data": ["月", "火", "水", "木", "金", "土", "日"] },
  "yAxis": { "type": "value" },
  "series": [{ "name": "文字数", "type": "bar", "data": [820, 1320, 960, 1500, 1100, 600, 300] }]
}
```

Mermaid のフローチャートやシーケンス図など：

```mermaid
flowchart LR
  A[Finder で .md を選ぶ] --> B{スペースキーを押す}
  B --> C[整った記事]
  B --> D[グラフと図]
```

[^1]: 脚注は文末に表示されます。

## App Review 备注（英文，填在「App 审核信息 → 备注」）

Velmo Viewer is a Quick Look preview extension for Markdown files. Its main feature runs inside Finder's Quick Look panel, not in the app window: the app hosts the extension, guides the user through enabling it, and provides its settings (theme, font size, text width, code wrapping, web images) with a live preview.

How to test:
1. Launch Velmo Viewer. The first-launch guide appears.
2. Click "Open System Settings…". In General > Login Items & Extensions > Quick Look (on macOS 13 and 14: Privacy & Security > Extensions > Quick Look), turn on Velmo Viewer. If another Markdown Quick Look extension is installed, turn it off, because macOS picks only one.
3. Back in the app, click "Test". A Quick Look panel opens the bundled sample document and the app confirms "Velmo Viewer is active".
4. In Finder, select any .md file and press Space to see the rendered preview (headings, tables, code highlighting, math, ECharts charts and Mermaid diagrams).

"Skip for Now" on the guide goes straight to the settings window, which also has the Test button.

No account or login is needed. The app collects no data. Network access is only used to load images from the web that a Markdown document links to, and it can be turned off in Settings ("Load Remote Images").

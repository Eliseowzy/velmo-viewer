- **Tables render correctly.** Tables with an empty cell (such as a blank top-left corner) no longer lose a column, and tables in files with Windows line endings or trailing spaces now display as tables.
- **Documents no longer go blank.** A file that starts with `---` but isn't front matter now shows its content, and files saved with a BOM show their first heading correctly.
- **Better bold and italics in Chinese and Japanese.** Text like `**加粗。**后面` is now bold.
- **Links to headings work.** Table-of-contents links such as `[Setup](#setup)` jump to the heading.
- **More HTML supported.** Common tags like `<mark>`, `<table>` and `<details open>` now render instead of showing as source.

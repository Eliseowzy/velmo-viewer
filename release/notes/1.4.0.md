- **Quick Look for source code.** Press Space to preview Swift, C/C++, Objective-C, Java, Python, JavaScript/TypeScript, Go, Rust, Ruby, PHP, shell, HTML/CSS, SQL, JSON, XML, YAML and more with syntax highlighting.
- **JSON Lines support.** Preview `.jsonl` and `.ndjson` files with each line highlighted as an independent JSON record. A malformed line does not prevent the remaining records from appearing.
- **Responsive large-file previews.** Source files are limited to the first 2 MiB. JSON Lines previews stop at a complete record and clearly indicate when later records are omitted.

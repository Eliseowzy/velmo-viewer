- **支援程式碼檔案快速預覽**：在 Finder 中選取 Swift、C/C++、Objective-C、Java、Python、JavaScript/TypeScript、Go、Rust、Ruby、PHP、Shell、HTML/CSS、SQL、JSON、XML、YAML 等檔案，按空白鍵即可查看語法高亮的原始碼。
- **支援 JSON Lines**：`.jsonl` 和 `.ndjson` 檔案會逐行按獨立 JSON 記錄高亮；某一行格式錯誤不會影響其他記錄顯示。
- **大型檔案預覽更穩定**：程式碼檔案最多讀取前 2 MiB；JSON Lines 會在完整記錄處停止，並明確提示後續記錄已省略。
